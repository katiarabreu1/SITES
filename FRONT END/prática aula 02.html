Aula Prático de HTML

Nesta aula, vamos construir uma landing page utilizando apenas HTML. O objetivo é entender a estrutura de uma página web antes de aplicar CSS.

Quero participar

Sobre o curso

Este curso foi criado para alunos que estão iniciando no desenvolvimento web. Primeiro aprendemos HTML, depois aplicamos CSS para melhorar o visual.

O que você vai aprender?

  • Estrutura básica de uma página HTML
  • Uso correto de títulos e parágrafos
  • Criação de links e menus
  • Inserção de imagens
  • Criação de listas, tabelas e formulários

Conteúdo da aula

  1. Criação do arquivo index.html
  2. Estrutura HTML básica
  3. Cabeçalho da página
  4. Menu de navegação
  5. Seções da landing page
  6. Formulário de contato
  7. Rodapé da página
